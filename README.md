# Autonomous Company v0.1

An AI-operated digital business control system.

## V0.1 scope

- CEO orchestration
- Research opportunity scoring
- Decision ledger
- Budget/risk policy
- Experiment model
- Minimal control panel
- Safe-by-default autonomous cycle

## Architecture

CEO -> Research -> Product -> Analytics -> Optimizer -> CEO

The system is intentionally constrained. Financial, legal, destructive, and irreversible actions require human approval.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

Open http://localhost:3000.

## Environment

See `.env.example`. No secrets are committed.
